# 风物诗 · 打包说明

把「弹琴 / MIDI 直接转 / 简谱转 / 谱图识谱 / 工具」合成一个桌面应用的打包流程。
本文件随 `dist/风物诗/` 一起分发。

---

## 1. 一键打包

```bat
打包.bat                  打包 exe 并装配可运行目录
打包.bat --clean          先清 build/ dist/ 再打
打包.bat --inno           打完顺手编译安装包
打包.bat --zip            顺手压一个便携 zip
打包.bat --no-stage       只出 exe，不装配工具脚本
```

等价于直接跑 Python：

```bat
python 风物诗\tools\build.py --clean --inno --zip
```

产物：

| 位置 | 内容 |
| --- | --- |
| `风物诗\dist\风物诗\风物诗.exe` | 主程序（双击即可跑） |
| `风物诗\dist\风物诗\_internal\` | Python 运行时与第三方包 |
| `风物诗\dist\风物诗\获取谱子\` | 工具脚本（运行时被就地加载） |
| `风物诗\dist\风物诗\parser.py` `player.py` | 被工具脚本动态加载 |
| `风物诗\dist\风物诗-便携版.zip` | 便携包（`--zip`） |
| `风物诗\dist\installer\*.exe` | 安装包（`--inno`） |

## 2. 为什么工具脚本要放在 exe 旁边

工具脚本（`获取谱子/*.py`）**不是被编译进 exe 的**，而是运行时用
`importlib.util.spec_from_file_location()` 就地加载的普通文件。它们各自按
`__file__` 反推 `ROOT` 去找 `parser.py`：

```python
ROOT = Path(__file__).resolve().parent.parent      # 例：获取谱子/retime.py → 仓库根
spec = importlib.util.spec_from_file_location("parser", ROOT / "parser.py")
```

所以目录结构必须是：

```
风物诗\                     ← exe 所在处 = 应用眼里的「仓库根」
    风物诗.exe
    _internal\
    获取谱子\               ← 应用按 <exe目录>\获取谱子 找它
        jianpu_to_score.py
        midi_to_score.py
        retime.py  add_hold.py  verify_original.py
        字母谱转谱.py  字母谱对账.py
        简谱识谱\
            识谱.py  imgio.py  audit.py  字模.json
    parser.py  player.py
```

好处：**用户可以自己改脚本而不用重新打包**（改完直接生效）。

## 3. 打包环境要求

| 组件 | 用途 | 装法 |
| --- | --- | --- |
| Python 3.12（含 tkinter） | 运行与打包 | 本机 Store 版即可 |
| `customtkinter` `pillow` `numpy` `keyboard` | 运行依赖 | `python -m pip install -r requirements.txt` |
| `pyinstaller>=6.0` | 打 exe | `python -m pip install pyinstaller` |
| Inno Setup 6 | 打安装包（仅 `--inno` 需要） | `winget install --id JRSoftware.InnoSetup` |

`打包.bat` 会**逐个候选实测**解释器（`python` → `py` → WindowsApps 路径），
取第一个真正能 `import PyInstaller` 的，并把选中的绝对路径打印出来。

## 4. 打包配置的几处刻意选择

`风物诗.spec`：

* **onedir，不用 onefile**。onefile 每次启动都要把 60+ MB 解压到临时目录，冷启动要好
  几秒；而且工具脚本本来就要以文件形式躺在 exe 旁边，onefile 会把结构搞乱。
* **`console=False`** —— 不要黑窗口（用户明确要求「原生窗口应用，不要黑框菜单」）。
* **`upx=False`** —— UPX 压缩会被部分杀软误报。
* `datas=collect_data_files("customtkinter")` —— 它的主题 json 是数据文件，不收集会崩。
* `hiddenimports` 含 `keyboard`（在 `play.py` 的函数体内 import）、`darkdetect`、
  `PIL._tkinter_finder`。

`安装包.iss`：

* **`PrivilegesRequired=lowest`** —— 装到 `%LOCALAPPDATA%\Programs\风物诗`，
  **安装时不要 UAC**。应用自己只在「点开始演奏」那一刻才提权。
* **没有 `[UninstallDelete]`** —— 卸载**绝不碰**用户数据。
* 版本号从 `app/paths.py` 的 `APP_VERSION` 读出来传给 ISCC，不会和程序里对不上。
* 检测到 `Languages\ChineseSimplified.isl` 才启用中文向导（Inno 官方不带中文）。

## 5. 用户数据在哪（卸载不删）

| 内容 | 位置 |
| --- | --- |
| 曲谱 / 简谱 / MIDI 队列 / 产物 | `文档\风物诗\` |
| 配置 / 背景缓存 / 字模中间产物 / 日志 | `%LOCALAPPDATA%\风物诗\` |

首次运行会把仓库现有的 `scores/` `简谱/` `change_base/` **复制一份**给应用用，
**只复制、不移动、不删除、不覆盖**；仓库里原有的乐谱文件此后也不再被写。

用环境变量可以改位置：

```
FENGWUSHI_DATA_DIR    覆盖数据目录
FENGWUSHI_CACHE_DIR   覆盖配置/缓存目录
FENGWUSHI_SCRIPTS     指定 获取谱子 目录
```

## 6. 换图标

图标是代码画的，不往仓库塞二进制：

```bat
python 风物诗\tools\build_icon.py
```

改 `tools/build_icon.py` 里的 `BG` / `ACCENT` / 文字即可，会同时生成
`assets/风物诗.ico`（7 个尺寸）与 `assets/风物诗.png`。
