# 【本曲是「四行谱」】每系统四行：
#   ① 旋律上声部 —— 只在与下方旋律音**同列**处落音（竖排和弦的上音）
#   ② 旋律行   —— 主旋律；红色歌词挂在这一行下面
#   ③ 中声部   —— 伴奏和弦的上音
#   ④ 低音     —— 伴奏和弦的下音 / 低音跑动
#   ③+④ 的竖排叠置按**同时和弦**输出到伴奏。① 整行印在**花括号之上**，而识谱器的
#   「上沿救援」窗口只到 0.42 倍字高（≈19px），本曲高出 0.58~0.69 倍字高（26~30px）
#   ⇒ **① 行整行丢失**；又因「往和弦里塞音不改时值」，拍数自检永远报不出来。
#   → 已记为**缺陷 20（旋律上声部整行印在花括号之上 → 上沿救援够不着 → 静默丢失）**；
#     本轮**不改工具层**（放宽救援阈值须全量 A/B 回归，而 42 首既有曲目的源谱图不齐），
#     按项目先例做**简谱层补正**。
#
